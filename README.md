# Williamson's Gig Supply Co. v5.0 — Endless Tycoon Edition

## Core direction
There is no final win screen or Game Over. Every December is an annual franchise review, and WGSC renews the branch for another year.

## Network ranks
Career Score determines permanent WGSC prestige:
- 🎵 New Franchise — 0+
- 🥉 Neighborhood Favorite — 3,000+
- 🥈 Regional Headliner — 6,000+
- 🥇 Regional Flagship — 9,000+
- 💎 Platinum Partner — 12,000+
- 👑 WGSC Elite Franchise — 15,000+
- 🌟 Hall of Fame Franchise — 18,000+

Hall of Fame is a prestige milestone, not an ending.
